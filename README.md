# 🌐 Sruti Gupta – Personal Portfolio

**A personal portfolio showcasing my journey, technical skills, projects, internships, and achievements as an AI-Powered Full Stack Developer.**

Built to highlight my experience in developing modern web applications and integrating AI-powered features into real-world solutions.

## ✨ Features

- **👩‍💻 About Me:** Introduction, education, and professional journey.
- **🛠️ Technical Skills:** Programming languages, frameworks, tools, and technologies.
- **💼 Experience:** Internship experiences and professional contributions.
- **🚀 Projects:** Selected full-stack and AI-powered projects.
- **🏆 Achievements:** Hackathons, certifications, and accomplishments.
- **📬 Contact:** Direct links to connect professionally.

## 🧰 Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins)
- Responsive Web Design
